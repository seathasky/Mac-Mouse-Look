# Mac Mouse Look

Mac Mouse Look turns hold-to-look into a keyboard toggle for Windows games running through Wine or CrossOver on macOS. It works with games that use the right mouse button to look around.

## Quick start

1. On macOS 14 or later, move `Mac Mouse Look.app` to Applications and open it.
2. Click the mouse icon in the menu bar, choose **Choose Game…**, and select the game’s `.exe`.
3. Launch the game as usual. Mac Mouse Look automatically finds the Wine session running that executable. With the game focused, tap <kbd>E</kbd> to hold right-click and show the gold reticle at the center of the game window. Tap <kbd>E</kbd> again or switch away to release the cursor and hide the reticle.

## Menu controls

| Menu item | What it does |
| --- | --- |
| **Choose Game…** | Select a game executable and remember its bottle. |
| **Recent Games** | Switch between your last 10 game and bottle combinations. The bottle name appears once the game connects. |
| **Shortcut → Record Shortcut…** | Set your own toggle key or key combination. |
